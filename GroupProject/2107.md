📘 README – Project Summary (Final Week)
🗓 Date: July 21, 2025

✅ Overview
This project was developed as part of a 4-week group assignment in collaboration with another student team. The goal was to build a Power Platform-based training application inspired by services like Udemy, where instructors can manage and publish their own courses, and students can register and interact with them.

Although chatbot integration and automated certificate generation could not be completed within the timeframe, we successfully implemented the following features:

⚙️ Implemented Features
A Power Apps-based application for both students and instructors.

Visual UI cues in the instructor app (text color and labels) to highlight new course registrations.

UI changes in the student app (background color) to show when enrollment is approved.

Instructors can send invoices to students via Power Automate email flows.

Students receive email notifications when their enrollment is approved or rejected.

When students mark a course as completed, an email notification is sent to the instructor.

User interface designed to allow simple registration without profile creation.

🛠 Technologies Used
Power Apps

Power Automate

SharePoint (as data storage)

Outlook (for email integration)

📩 Notification System
Instead of chatbot messaging, we implemented an email-based communication system using Power Automate. This allowed for timely and automated messaging between students and instructors with:

Custom invoice messages

Status updates

Course completion notifications

🔚 Notes
This app is designed primarily for desktop use, and includes in-app notification banners (Notify() in Power Apps) to give users real-time feedback upon submission or other key actions.
